# Remotion visual direction

## Durable guidance
- Design each scene around one dominant read: one claim, one proof object, minimal support text.
- Prefer proof objects over generic decorative UI clutter: real code, terminal output, charts, repo diffs, product screens, message bubbles, metrics, or one large interface element.
- Let typography carry the hierarchy: larger primary line, fewer words, and cut on-screen copy aggressively.
- Motion should clarify sequence rather than decorate; stagger reveals and keep non-essential elements calm.
- Premium feel usually comes from cleaner composition, more negative space, restrained color, and selective depth rather than more effects.
- Reuse a small set of scene archetypes instead of inventing every scene from scratch.
- A reliable composition formula: big claim -> immediate proof visual -> short supporting label -> clean motion reveal -> hold.

## Thumbnail iteration pattern
- When a thumbnail direction works, iterate the strongest structure rather than restarting.
- For the Opus 4.7 poster direction based on `01b`, three tested hook-line variants were:
  - `RUNS LONGER`
  - `PUSHES BACK`
  - `BETTER JUDGMENT`
