# .agents Standard Video — "The Standard That Will Connect All AI Agents"

**Format:** Short-form vertical (1080x1920), ~60 seconds
**Tone:** Alpha-drop, insider knowledge, fast-paced
**Music:** Dark techy beat, low bass

---

## SCENE 1: Hook (0-5s)
**Visual:** Dark screen, glitch effect, then text slams in
**Text on screen:** "Every AI tool has its own config folder."
**Voiceover:** "Every AI tool has its own config folder. Claude has dot-claude. OpenCode has dot-opencode. Codex has AGENTS.md."

## SCENE 2: The Problem (5-12s)
**Visual:** Logos/names flying in from different directions — ".claude/", ".opencode/", "AGENTS.md" — chaotic, overlapping
**Text on screen:** ".claude/ → .opencode/ → AGENTS.md → 🤯"
**Voiceover:** "Your skills, your commands, your agent instructions — locked inside each tool. You switch tools, you lose everything."

## SCENE 3: The Convergence (12-22s)
**Visual:** All the scattered elements start gravitating toward center. A glowing `.agents/` folder materializes.
**Text on screen:** ".agents/"
**Voiceover:** "But something is converging. Quietly. The dot-agents directory standard. One folder. Every tool reads it."

## SCENE 4: The Structure — Alpha Drop (22-38s)
**Visual:** Terminal-style animation, folder tree typing out line by line
```
~/.agents/
├── skills/       ← shared across ALL tools
├── commands/     ← reusable prompt templates  
├── agents/       ← agent definitions
└── AGENTS.md     ← project instructions
```
**Voiceover:** "Skills. Commands. Agent definitions. One AGENTS.md for project instructions. Write it once — Claude Code, Codex, Cursor, OpenCode, DotAgents — they all pick it up. Zero config."

## SCENE 5: The Killer Insight (38-48s)
**Visual:** Split screen comparison. Left side: copy-pasting configs between tools (red X). Right side: single .agents/ folder glowing (green check).
**Text on screen:** "Write once. Every agent reads it."
**Voiceover:** "This is the package-dot-json moment for AI agents. One standard file that defines how agents work in your project. Twenty-five plus tools already support it."

## SCENE 6: CTA (48-60s)
**Visual:** DotAgents logo animates in with spring bounce. GitHub stars counter ticking up.
**Text on screen:** "DotAgents — shipping .agents/ support now"
**Subtext:** "github.com/aj47/speakmcp"
**Voiceover:** "We're building DotAgents — the voice-first agent desktop that reads your dot-agents folder natively. Link in bio. Go drop a star."

---

## Key Talking Points (for caption/description):
- The .agents/ standard is the tool-agnostic version of .claude/ and .opencode/
- Skills use SKILL.md format (YAML frontmatter + markdown) — already adopted by 25+ tools
- AGENTS.md has 17K+ stars on GitHub, adopted by Codex, Cursor, Google Jules, Aider
- DotAgents reads ~/.agents/skills/ automatically — zero config skill sharing
- This is the "package.json moment" for AI agents
