# Experimental Media Lab

## Purpose
Capture durable media taste, reusable production vocabulary, reference patterns, and preview outcomes from the Experimental Media Lab loop.

## Core thesis
The strongest current vocabulary is:
- hook-first structure
- type-safe motion
- interaction that explains the system

This is more durable than generic AI launch gloss or shallow trend mimicry.

## Durable patterns extracted
- Material-state transformation can carry abstract meaning.
- Strong type hierarchy should anchor product motion.
- The first 3-6 seconds should be designed as a packaging layer.
- Interactive behavior can replace explanation copy.
- Caption systems should have modes, not one generic style.
- Thumbnail design works better as a matrix than as isolated intuition.
- Editability matters; scenes should be preserved as reusable layer recipes.

## What to avoid
- Generic AI launch-page gloss: polished but interchangeable.
- Surface-level anti-AI aesthetics without message function.
- Motion that compromises type legibility.
- Trend imitation without a reusable system behind it.

## Reusable systems to build first
1. Typography-first promo scenes
2. AJ caption preset kit
3. Hook opener family
4. Thumbnail test matrix
5. Interactive specimen/demo template
6. Outcome-first demo walkthrough

## Recommended capture workflow
For each cycle:
1. Add strongest references + extracted patterns to experiments.md.
2. Summarize only the best new ideas in digest.md.
3. Log sources reviewed and promotions/archives in run-log.md.
4. If a direction becomes visually legible, create/update a preview page.
5. If a direction proves durable, add/update this knowledge note so future sessions can build on it.

## New durable signals from 2026-04-17 follow-up
- **Guided demo flow** is emerging as a strong presentation pattern: continuous recording, contextual annotation, smooth transitions, and inline CTAs/readiness cues.
- **Kinetic typography** is worth treating as a reusable system, not a decorative trick — especially for hooks, title cards, and emphasis captions.


## New durable signals from 2026-04-17 second follow-up
- **Outcome-first demo structure** is now a durable signal: one audience, one use case, one proof arc, and one CTA beat broad feature tours.
- **Micro-motion messaging compression** is useful when it summarizes capability clusters or creates stronger chapter separation.

- Preview: http://127.0.0.1:4323/experimental-media-lab-preview/outcome-first-demo.html


## New durable signals from 2026-04-17 third follow-up
- **Atmospheric scrollytelling with conversion architecture** is a strong page-level pattern: mood earns attention, but proof and CTA timing must stay explicit.
- **Motion blocking boards** are useful as a lower-lift bridge between inspiration and full production when testing camera/movement direction.


## New durable signals from 2026-04-17 fourth follow-up
- **Proof beats should become first-class scene units**: one quantified result, one context line, one emphasis move.
- **Microsite motion needs production constraints**: performance budgets, mobile simplification, and CTA clarity are part of the style system, not post-hoc cleanup.


## New durable signals from 2026-04-17 fifth follow-up
- **Dual-output capture is now a durable system pattern**: one recording should fan out into demo, doc, and reusable still assets whenever possible.
- **Checkpointed explainer navigation** is a promising educational layer when AJ wants exploration without dumping all context at once.


## New durable signals from 2026-04-17 sixth follow-up
- **Session architecture is now a durable distribution pattern**: Shorts, main videos, and follow-up assets should be designed as connected systems.
- **Hover-reveal cover cards** are a promising lightweight interaction pattern for collections, launch hubs, and concept intros.
