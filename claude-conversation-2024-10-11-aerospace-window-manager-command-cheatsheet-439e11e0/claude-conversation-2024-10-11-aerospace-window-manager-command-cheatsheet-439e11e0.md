# AeroSpace Window Manager Cheatsheet

## Most Common Commands

| Shortcut | Action |
|----------|--------|
| Alt + H/J/K/L | Focus left/down/up/right |
| Alt + Shift + H/J/K/L | Move window left/down/up/right |
| Alt + 1-9 | Switch to workspace 1-9 |
| Alt + Shift + 1-9 | Move window to workspace 1-9 |
| Alt + / | Toggle between horizontal and vertical tiling layout |
| Alt + , | Toggle between horizontal and vertical accordion layout |
| Alt + Tab | Switch to previous workspace |
| Alt + Shift + - | Decrease window size |
| Alt + Shift + = | Increase window size |

## Workspace Management

| Shortcut | Action |
|----------|--------|
| Alt + [A-Z] | Switch to named workspace (A through Z) |
| Alt + Shift + [A-Z] | Move window to named workspace (A through Z) |
| Alt + Shift + Tab | Move workspace to next monitor |

## Layout Control

| Shortcut | Action |
|----------|--------|
| Alt + Shift + ; | Enter service mode |
| Alt + Shift + ; then R | Reset layout (flatten workspace tree) |
| Alt + Shift + ; then F | Toggle between floating and tiling layout |

## Window Management

| Shortcut | Action |
|----------|--------|
| Alt + Shift + ; then Backspace | Close all windows except current |
| Alt + Shift + ; then Alt + Shift + H/J/K/L | Join with left/down/up/right window |

## System Commands

| Shortcut | Action |
|----------|--------|
| Alt + Shift + ; then Esc | Reload config and exit service mode |

## Notes

- The `Alt + Enter` shortcut for opening a terminal is commented out in the config file. Uncomment it if needed.
- Some shortcuts use letters (A-Z) for named workspaces. Adjust these based on your preferences.
- The config file allows for customization of gaps, after-login commands, and other settings not listed in this cheatsheet.
