# Current Fitness Program

## Primary objective
Build durable knees for tennis while improving posture, lower-body stability, and pull strength.

## Current session template
### Lower body + knee resilience day
1. Warm-up: 5–8 min bike or incline walk
2. Split squats — 3 x 6–8 each side, slow eccentric
3. Step-downs or reverse lunges — 3 x 6–8 each side
4. Spanish squat holds — 3 x 30–45 sec
5. Romanian deadlifts — 3 x 8–10
6. Single-leg calf raises — 3 x 8–12 each side
7. Tib raises — 2–3 sets if convenient
8. Rows + face pulls — optional upper-back finisher

## Programming rules
- Start unilateral lower-body work with the left leg.
- Match right-side quality to left-side quality.
- Favor control, tempo, and stability over load.
- If one side gets extra work, it should be the left.

## Current priority
Left knee stability and left-leg strength symmetry.
