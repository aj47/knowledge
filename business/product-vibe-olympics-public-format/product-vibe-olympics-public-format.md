# Vibe Code Cup — Public Format and Rules

> Update 2026-03-14: The event is now branded **Vibe Code Cup**. This doc reflects the renamed public framing and the website decisions captured in `vibe-code-cup-notes-2026-03-14.md`.

## What it is

Vibe Code Cup is a live AI-first software competition.

Competitors get a surprise challenge and 90 minutes to build, test, and submit working software using any AI tools they want.

When time runs out, submissions are judged as standalone software.

## What you should expect

- The exact challenge is revealed only when the round starts
- You will have **90 minutes total** to build and submit
- You may use any AI coding tools during the round
- Your final submission must run without API keys, network access, or runtime LLM calls
- Top submissions may advance to a live head-to-head finale

## How submissions are judged

Submissions are evaluated on:
- correctness
- submission speed
- execution speed

Additional finale formats may be used for top entries depending on the round.

## Submission requirements

You will submit a GitHub repo that includes:
- your source code
- a README
- a run script that allows us to evaluate your submission

Full submission contract will be provided at the start of the round.

## Rules

- Use any AI tools you want during the build
- Work must be your own during the competition window
- No sharing solutions with other participants
- Final submissions must run standalone
- Late submissions may not be accepted
- Specific challenge details and evaluation inputs may remain hidden until judging

## Why this is different

This is not a traditional hackathon.

It’s a live, time-constrained software competition built around execution under pressure.
