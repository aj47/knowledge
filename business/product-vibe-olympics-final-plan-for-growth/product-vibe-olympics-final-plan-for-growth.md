# Vibe Code Cup — Pilot Plan

> Update 2026-03-14: Name changed from **Vibe Olympics** to **Vibe Code Cup**. Public-facing materials should use the new name and the landing-page positioning captured in `vibe-code-cup-notes-2026-03-14.md`.

**Prepared for:** Head of Growth + leadership  
**Prepared by:** Arash Joobandi  
**Date:** 2026-03-12

## Goal
Run the first public Vibe Code Cup pilot within 7 days.

## Event Format
- Open event
- Secret challenge revealed at start
- 90 minutes total for build, test, and submission
- Any AI tools allowed during the round
- Final submission must run standalone
- Top entries advance to a live finale

## What Participants Should Expect
- They will know the format, rules, and submission contract in advance
- They will not know the actual challenge in advance
- They must submit a GitHub repo before the 90-minute timer ends
- Late submissions are not accepted
- Runtime API keys, network calls, and LLM calls are not allowed in final submissions

## Judging
Submissions are scored on:
- correctness
- submission speed
- execution speed

Finale format:
- top submissions face off live in a head-to-head showdown

## Pilot Scope
Target:
- 16–32 registrants
- 8–16 real submissions
- 4–8 invited featured competitors

Format for pilot:
- one build round
- one scoring pass
- one live finale

## Deliverables Before Launch
1. Public rules / format page
2. Internal secret challenge doc
3. Registration page or form
4. Starter repo
5. Hidden test suite
6. Scoring harness
7. Submission intake flow
8. Discord / event coordination hub
9. Stream run-of-show
10. Finale runner / visualizer
