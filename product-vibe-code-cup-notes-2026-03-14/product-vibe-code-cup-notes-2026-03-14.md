# Vibe Code Cup — decisions and learnings

Date: 2026-03-14

## Naming
- Current event name: **Vibe Code Cup**
- Reason: clearer than Vibe Olympics and feels more premium / competitive

## Positioning
- Public framing should be broad enough for builders, viewers, and sponsors
- Event is open, but featured competitors can still be invited / sponsored
- Core idea: the event surfaces the best builders, workflows, and tools

## Hero copy direction
- Headline: **Where the best builders, workflows, and tools rise to the top.**
- Supporting line: **All tools allowed. 90-minute hack sprint. Hard challenge disclosed at kickoff.**
- Builder callout used in form/entry section: **Bring your tools. Show your workflow. Prove it.**

## Event format decisions
- Challenge stays secret until kickoff
- 90 minutes total includes build, test, and submission
- All tools allowed during build
- Final submissions must run standalone
- Judging dimensions: correctness, submission speed, execution speed
- Top entries advance to a streamed finale / showdown

## Landing page decisions
- Page should appeal to three audiences: builders, viewers, sponsors
- First fold should have much less text than earlier drafts
- Hero should eventually support a strong background video
- Sponsor placeholders should say variations of "Your Brand Here"
- Placeholder prize pool can be shown as **$5,000** until finalized

## Style decisions
- Reuse techfren brand language rather than generic cyber/esports styling
- Favor the techfren font stack / typography direction
- Cleaner, more editorial dark layout with restrained neon accents
- Current preferred direction evolved from Neon Grid into a more techfren-aligned version
