# Vibe Code Cup Retro

## Core thesis
- The current strongest framing is that the real edge in AI coding is not just tool choice.
- The edge comes from **workflow, prompting, research, feedback loops, harness engineering, and execution under pressure**.
- The competition format made that hidden layer more visible than benchmarks alone.

## Proven reusable framing
- AI coding is becoming less about isolated tool selection and more about operator skill plus system design.
- Vibe Code Cup is useful as evidence because it shows real builders operating under time pressure with public outputs.
- The retro should explain both the broader vision and the concrete challenge details.

## Video direction
- Target length: **8–15 minutes**.
- Include more context on the actual challenge, the broader vision, and Chess Agents / challenge mechanics.
- Avoid repetitive phrasing and weak claims that do not sound true to AJ.
- Best direction is proof-led, with Saturday's event as the moment the concept became real.
