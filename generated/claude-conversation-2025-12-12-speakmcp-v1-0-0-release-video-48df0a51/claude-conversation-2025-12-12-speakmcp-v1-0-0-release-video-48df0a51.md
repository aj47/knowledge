**SpeakMCP v1.0.0 — Open Source Voice & Text MCP Client | Voice-Controlled AI Agents**

SpeakMCP is an open source MCP (Model Context Protocol) client with voice and text input. Control AI agents with your voice using a simple hotkey—hold to record, release to execute.

**🔧 Fully Modular Architecture**
Every component is swappable:
- Transcription: OpenAI Whisper, Groq Whisper, or bring your own STT
- LLM: OpenAI, Anthropic Claude, Google Gemini, Groq, any OpenAI-compatible API
- TTS: Configurable text-to-speech output
- System prompt: Full control over agent behavior

**⚡ MCP Integration**
Standard MCP server configuration. Connect to filesystem, databases, APIs, or any MCP-compatible tools. Same JSON config format as Claude Desktop.

**📱 Cross-Platform**
- macOS (Intel & Apple Silicon)
- Android APK
- iOS
