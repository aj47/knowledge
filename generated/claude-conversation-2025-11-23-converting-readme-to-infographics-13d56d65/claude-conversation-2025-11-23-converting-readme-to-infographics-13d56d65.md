## Tips for Using These Prompts:

- **Adjust specificity**: Add brand colors if you have specific hex codes (e.g., "vibrant blue #4A90E2")
- **Iterate on style**: Try variations like "flat design," "3D rendered," "hand-drawn illustration," or "photorealistic mockup"
- **Control composition**: Specify "centered," "asymmetric," "golden ratio," or "rule of thirds"
- **Refine details**: Add lighting terms like "soft shadows," "rim lighting," or "ambient occlusion" for depth

Each prompt follows the guide's structure: front-loaded subject, clear action/layout, specific style, and contextual details within 30-80 words.\n
