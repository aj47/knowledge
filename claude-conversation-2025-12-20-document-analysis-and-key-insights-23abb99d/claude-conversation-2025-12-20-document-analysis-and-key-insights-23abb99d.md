- They're simultaneously genius polymaths AND confused grade schoolers, seconds from getting jailbroken
- Benchmarks are now basically meaningless because teams "benchmaxx" by growing capability spikes around test sets

**3. Cursor revealed a new app layer**
- "Cursor for X" became a category—LLM apps that bundle context engineering, orchestrate multiple calls, provide vertical-specific GUIs, and offer an "autonomy slider"
- LLM labs graduate the college student; apps deploy them as professionals in specific verticals

**4. Claude Code changed what AI "looks like"**
- First convincing LLM agent that runs on YOUR computer with YOUR context
- OpenAI got this wrong by focusing on cloud containers—we're in a "slow enough takeoff" that localhost + human-in-the-loop wins
- AI went from "website you visit" to "spirit that lives on your computer"

**5. Vibe coding crossed the threshold**
- Programming via English, forgetting code exists
- Empowers regular people MORE than professionals (LLMs flip technology diffusion)
- Code is now "free, ephemeral, malleable, discardable after single use"

**6. Gemini Nano Banana = LLM GUI**
- Text is favored for computers, not humans—people prefer visual/spatial info
- Just like traditional computing invented the GUI, LLMs need to speak in images, infographics, web apps
- The joint capability of text gen + image gen + world knowledge tangled in weights is the key
