# Strategic Direction — Harness Engineering Leverage

## Execution rule
All future decisions and task generation should optimize for:

> Maximum leverage, fastest compounding, highest signal-to-noise execution.

## Core shift
Move away from low-leverage work: isolated building, tweaking, local optimization, and product polish that does not create distribution, authority, or repeatable expertise.

Prioritize leverage:
- **Distribution:** audience growth, platforms, Alpha Signal, video, workshops, reusable public artifacts.
- **Authority:** teaching, workshops, crisp frameworks, proof-backed explanations.
- **Compounding expertise:** repeated harness-engineering examples, evaluations, feedback loops, and iterations.

## Primary domain
AJ's primary domain is **Harness Engineering**: designing environments, constraints, and feedback loops for agents so agentic work becomes measurable, repeatable, and trustworthy.

Positioning shift:
- From: builder of tools/products.
- To: system designer + teacher of agent harnesses.

DotAgents remains valuable as an internal tool, demo asset, and proof surface, but should not be treated as the primary product unless it directly supports leverage, teaching, distribution, or workshop outcomes.

## Workshop design principles
Goal: participants leave with a working harness.

Structure:
1. What harness engineering is.
2. Anatomy: problem → evaluation → loop → logging.
3. Guided build: step-by-step, command-by-command.

Constraints:
- Enforce small, simple problems.
- Provide starter templates.
- Avoid broad agent hype; prefer concrete systems design.
- Every example should expose objective feedback, writable surface, stopping criteria, and logs.

## Content strategy
Record the workshop and turn it into reusable content:
- polished companion video
- clips/posts
- diagrams/templates
- future workshop improvements
- authority proof for more opportunities

Content is the leverage engine: workshop → video → audience → more workshops.

## Leverage tracker
When choosing or generating tasks, label the work:
- **Leverage work:** creates distribution, authority, reusable teaching assets, repeatable workshop systems, expertise compounding, or strong signal.
- **Non-leverage work:** local tweaks, isolated building, private polish, open-ended optimization, or work without a distribution/learning loop.

Default action:
- Prefer leverage work.
- Convert necessary non-leverage work into a leverage artifact when possible: demo, template, clip, teaching note, benchmark, workshop exercise, or reusable checklist.
- If work cannot be tied to distribution, authority, or compounding expertise, deprioritize it.


## Objective workbench card primitive
Before turning any “improve this” agent task into workshop material or a reusable harness example, define a small objective workbench card:
- target / desired improvement
- oracle or evidence source
- editable surface
- budget / constraints
- regression to reject
- receipt or log format
- stop rule

This keeps harness-engineering work measurable and prevents generic optimization or spectacle from outranking proof-backed teaching artifacts.

## Constraint Ladder Arcade workshop primitive
For the Alpha Signal / Harness Gym anchor artifact, prefer a tiny constraint-ladder exercise over a broad demo. The exercise should make harness engineering tactile within minutes:
- choose one small, legible domain such as `Tiny Runtime Optimizer` or `Tiny Chess Move Agent`
- expose the oracle, editable surface, constraints/budget, regression, log, and receipt visibly
- let participants progress through increasingly strict cards or levels
- end with a leaderboard/readout or comparable receipt, so the point is the harness loop rather than the toy domain

Use this as the first concrete workshop artifact before designing broader show, product, or spectacle layers.

## Systems to build around this direction
- Workshop iteration system: prep → run → record → feedback → improve → repeat.
- Content production loop: workshop/video source material → polished content → distribution → audience feedback → next workshop.
- Expertise compounding loop: small harness examples → eval/logging lessons → reusable templates → teaching assets.
